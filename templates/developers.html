Talent Graph

Career intelligence for people, employers, and AI agents.

Aptura exposes talent intelligence through three layers: public or authorised API, MCP server for AI systems, and WebMCP tools for browser-based agents.

Get API accessReview approval rules
read -> propose -> act

Read tools

searchTalent, getCandidateProfile, getSkillEvidence, matchCandidateToRole, analyseResume, getCareerReadiness, getSkillGap.

Proposal tools

draftResumeChange, draftCoverLetter, draftCandidateMessage, proposeProfileUpdate.

Action tools

publishJob, inviteCandidate, submitApplication, sendMessage. Auth and confirmation required.

Strict source separation.

Third-party job descriptions, candidate content, and external text are untrusted input. Responses should separate user-authored, AI-generated, verified, and third-party data.

Authentication

Action tools require proper authentication, authorisation, and rate limits.

Audit logs

Human approvals, rejections, and AI recommendations should be recorded.

Structured JSON

Tools should return predictable schemas rather than loose text blobs.
